# Contribution Log

> **Why this file exists:** the SE4050 assignment requires *individual
> contributions* (viva) and *weekly commits*. Every member appends one row per
> work session. This is the single place where who-did-what is recorded.

## How to use

1. Add one row at the **bottom** of the table each time you finish a work block.
2. Keep the row **one line** — no long paragraphs; a hyperlink to the relevant
   file/PR/notebook is fine.
3. **Never delete or edit other members' rows.** If a correction is needed, ask
   the member who wrote the row.
4. Weekly commit cadence: at least one commit per member per week with a row
   here to match.
